# STM32 心电信号采集与 OLED 波形显示系统

## 1. 项目简介

本项目基于 **STM32F103C8T6**，通过 **AD8232 心电模块** 采集信号，并在 **SSD1306 OLED** 上实时显示，同时通过串口输出数据。

---

## 2. 硬件连接（已更新为 v3.0 原理图）

| 模块 | 引脚 | 说明 |
|------|------|------|
| AD8232 OUTPUT | PA5 | ADC输入 |
| OLED SCL | PB8 | 软件I2C |
| OLED SDA | PB9 | 软件I2C |
| UART1 TX | PA9 | 蓝牙/串口输出 |
| UART1 RX | PA10 | 蓝牙/串口输入 |
| KEY1 (SW2) | PB4 | 按键（低电平有效） |
| KEY2 (SW3) | PB5 | 按键（低电平有效） |
| BUZZER | PB13 | 低电平驱动（经三极管） |

> ⚠️ 注意：PB4 默认被 JTAG 占用，代码中已关闭 JTAG，仅保留 SWD。

---

## 3. 功能说明

- ECG 信号采集（500Hz）
- 数字滤波（高通/低通/陷波）
- R 波检测
- 心率计算
- OLED 实时波形显示
- UART / 蓝牙数据输出

---

